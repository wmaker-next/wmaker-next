Window Maker IPC protocol
=========================

Transport: AF_UNIX SOCK_STREAM, one listening socket per managed X
screen, path $XDG_RUNTIME_DIR/wmaker/ipc.<display-key> (or
/tmp/wmaker-<uid>/ipc.<display-key> when XDG_RUNTIME_DIR is unset).
<display-key> is the X display name with a screen suffix appended if
absent and every byte outside [A-Za-z0-9] mapped to '_', so :0 and
:0.0 both resolve to "_0_0". Clients may override the path with the
WMAKER_IPC_SOCKET environment variable, the server ignores that
variable when choosing where to bind.

Wire header (16 bytes, native byte order):

    offset 0   uint8_t  magic[8] = "wmaker0\n"
    offset 8   uint32_t length     payload bytes following the header
    offset 12  uint32_t type       request/reply id, or (1u<<31)|n for events

The server caps length at 1 MiB and drops the connection on a frame
that exceeds it or whose magic does not match.

Every non-empty payload is a textual property-list description as
produced by WMGetPropListDescription() and accepted by
WMCreatePropListFromDescription(). Receivers append a NUL after the
length-prefixed payload before parsing and reject embedded NUL bytes.

Request types
-------------
    0  COMMAND         payload: ((verb, arg, ...), ...)
                       reply:   {success=YES|NO; error="...";}
                                or an array of these when more than one
                                command was sent
    1  SUBSCRIBE       payload: ("workspace", "tick", ...)
                       reply:   {success=YES;}
                                followed immediately by a tick event
                                with first=YES when "tick" was named
    2  GET_WORKSPACES  reply:   ({name="..."; index=N; current=YES|NO;}, ...)
    3  GET_WINDOWS     reply:   ({id="0x..."; class="..."; instance="...";
                                  title="..."; workspace=N;}, ...)
    4  GET_VERSION     reply:   {version="..."; display="..."; screen=N;
                                 pid=N; socket="...";}
    5  SEND_TICK       payload: a single proplist string
                       reply:   {success=YES;}
                                a tick event with first=NO carrying the
                                decoded string is broadcast first

Event types (type field = (1u<<31) | id)
----------------------------------------
    0  workspace   {change="focus"|"create"|"destroy"|"rename";
                    index=N; name="...";}
    1  window      {change="manage"|"unmanage"|"focus"|"title"; id="0x...";}
    2  shutdown    {change="exit"|"restart";}
    3  child_exit  {pid=N; status=N; signal=N; wait_status=N;
                    source="dock"|"menu"|"helper"|"unknown"; slot=N;}
    4  dialog      {kind="message"|"input"|"crash"; title="..."; text="...";}
    5  tick        {first=YES|NO; payload="...";}
    6  screenshot  {path="..."; mode="screen"|"window"|"partial";
                    screen=N; workspace=N;}
    7  display_power
                   {state="on"|"off"; source="ipc"|"randr"|"screensaver";}
    8  sound       {event="shade"|"unshade"|"maximize"|"unmaximize"|
                   "iconify"|"deiconify"|"hide"|"unhide"|"appstart"|
                   "appexit"|"dock"|"undock"|"kaboom"|"startup"|
                   "shutdown"|"workspace"|"screenshot"|"lock";
                   screen=N; workspace=N;}

workspace, window, screenshot and sound are screen-scoped, the rest are process-scoped.

display_power is emitted on every actual transition of the global
display_off flag regardless of source. The DisplayOffCommand and
DisplayOnCommand defaults hooks fire only for the randr and
screensaver sources so a scripted `display-power off` does not
recursively launch the configured locker.

Command verbs (request type 0)
------------------------------
    reconfigure
    restart [WM]
    exit
    kill-session
    workspace next|prev|last|N
            next and prev honor the SkipEmptyWorkspaces option and skip
            workspaces holding no non-omnipresent windows. last and N
            are explicit targets and are never filtered
    window-workspace XID +N|-N|N
            move (N), add (+N) or remove (-N) the window's workspace
            membership; N is a 0-based workspace index
    move-to-edge left|right|up|down [snap|nosnap]
            slide the focused window in the named direction until it
            touches the screen edge. With snap (the default) it stops
            first at the nearest intervening window edge; nosnap goes
            straight to the screen edge. A window already at the screen
            edge jumps to the adjacent head's near edge, keeping its
            perpendicular position
    grow-to-edge left|right|up|down
            grow the focused window toward the named screen edge,
            keeping the opposite edge fixed and stopping at the nearest
            intervening window edge. Skipped when the window is
            fullscreen or maximized; unshades a shaded window first.
            Aborts when the result would shrink it or change nothing
    shrink-to-edge left|right|up|down
            shrink the focused window by up to half, keeping the named
            edge fixed and moving the opposite edge inward, stopping
            earlier at the nearest intervening window edge or the
            size-hint minimum. Same skip and unshade behavior as
            grow-to-edge; aborts when the final size is unchanged
    set-layout LAYOUT [workspace N] [master_count N] [master_ratio F]
            switch workspace N (current by default) to LAYOUT, which is
            one of float, tile, tileh, grid, monocle (case-insensitive);
            optional master_count and master_ratio tune the tiling
            parameters of the same workspace
    dock-launch SLOT
    show-all
    show-desktop
            toggle the EWMH "showing desktop" state: iconify all
            non-skip windows across all workspaces and set
            _NET_SHOWING_DESKTOP to 1, or restore the previously
            iconified windows and set it to 0
    arrange-icons
    hide-application XID
    hide-others XID
    workspace-new [count]
            create count (default 1) new workspaces
    workspace-delete N
            delete workspace N (1-based). Rejected when the
            workspace is in use by any non-omnipresent window
    window-close XID
            send WM_DELETE_WINDOW to the window and ping it
            via _NET_WM_PING
    display-power on|off
    play-sound EVENT
            emit a sound event on the IPC stream; EVENT is one of
            shade, unshade, maximize, unmaximize, iconify, deiconify,
            hide, unhide, appstart, appexit, dock, undock, kaboom,
            startup, shutdown, workspace, screenshot, lock.
            Requires the wmsoundd daemon to be subscribed to
            produce audio; the verb itself only emits the event
    info

An unknown verb yields {success=NO; error="unknown command '...'";}
and the connection stays open.
